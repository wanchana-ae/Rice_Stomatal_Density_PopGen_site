🧬 Rice Stomatal Density PopGen — Project Overview

Wanchana · 2026
Project Tree Viewer

Population-genetics analysis of stomatal-density candidate genes in rice (Oryza sativa). IQ-TREE phylogenies were built both for the pooled SNP panel across all 24 candidate genes (a single combined tree) and separately for each gene's own SNP region, then linked back to variety names and ADMIXTURE K2/K3/K5 population groups.

📊 Interactive Tree Viewer

Browse the combined 24-gene tree or any of the 20 individual gene trees (rectangular / circular / unrooted layouts, search by sample or variety, colour by K-group, export the current view as PNG/JPG/PDF, and export the accession list of whichever tree is selected as a CSV).

📅 Timeline

  • Combined tree — IQ-TREE (GTR+ASC, 1000 UFBoot / 1000 SH-aLRT) on SNPs pooled across all 24 candidate genes, 553 accessions.
  • Per-gene trees — run_all_gene_trees.sh built an independent IQ-TREE per gene; 20 of 24 genes had enough SNPs to resolve a tree (4 skipped — too few SNPs).
  • Relabeling & QC — tips matched against variety_metadata.csv and population_groups_K2/K3/K5.csv; unmatched tips shown as UNKNOWN_<code>.
  • Interactive viewer — D3-based tree viewer with export (PNG/JPG/PDF/CSV) built on top of the verified tip mapping.
